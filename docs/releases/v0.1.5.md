Windows / Mac用のシステム音声メーター、DAMeter 0.1.5の試用版（Pre-release）です。今回はMac版のフローティング表示で、サイズ変更の処理と操作位置を見直しました。

## ダウンロード

下の **Assets** または次のリンクから、自分のパソコンに合うファイルを選んでください。

| 使用するパソコン | ダウンロード |
| --- | --- |
| Windows 10 / 11（64bit） | [DAMeter-win-x64.zip](https://github.com/atstti/codex/releases/download/v0.1.5/DAMeter-win-x64.zip) |
| Mac・Apple Silicon（M1以降、macOS 15以降） | [DAMeter-osx-arm64.dmg](https://github.com/atstti/codex/releases/download/v0.1.5/DAMeter-osx-arm64.dmg) |
| Mac・Intel（macOS 15以降） | [DAMeter-osx-x64.dmg](https://github.com/atstti/codex/releases/download/v0.1.5/DAMeter-osx-x64.dmg) |

更新前に旧版を完全終了してください。WindowsはZIPを展開して `DAMeter.exe` を起動します。MacはDMGを開き、`DAMeter.app` を「アプリケーション」へ移動して起動します。.NETの別途インストールは不要です。Mac用のZIPと、各CPU向けの `SHA256SUMS-*.txt` もAssetsにあります。

## Mac版の変更

- メーターの見えている盤面の右下隅からサイズ変更できるよう、操作領域の位置を変更しました。横型ピーク・縦型ピーク・アナログVUの3表示で、拡大・縮小や表示切替に追従します。
- ドラッグ中はポインターを捕捉し、ウィンドウ内の座標を基準に幅・高さを更新します。ボタンを離すか捕捉が解除された際に、操作中の状態を解放する構成にしました。
- 拡大・縮小を繰り返す操作と、最小サイズ120×120まで縮めてから再び拡大する操作に対応する処理へ見直しました。

周囲の背景は引き続き初期状態で非表示です。メーターの移動・右クリックメニュー・クリック透過とメニューバーからの復帰を維持しています。Windows版の表示操作と、両OSの音声取得コードは変更していません。

## Macの起動・収録許可

Mac版はad-hoc署名で、Developer ID署名・Apple公証はありません。初回起動がブロックされた場合は、配布元を確認し「システム設定 → プライバシーとセキュリティ」の「このまま開く」を使用してください。

許可済みでも収録許可の案内が繰り返し出る場合は、DAMeterを完全終了し、「画面収録とシステムオーディオ録音」の一覧からDAMeterを「−」で削除します。その後「＋」で `/Applications/DAMeter.app` を追加し、許可をオンにして起動してください。
