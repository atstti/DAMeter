Windows / Mac用のシステム音声メーター、DAMeter 0.1.6の試用版（Pre-release）です。Mac版のサイズ変更中の跳ねと、上端への移動を妨げる透明な余白に対応しました。

## ダウンロード

下の **Assets** または次のリンクから、自分のパソコンに合うファイルを選んでください。

| 使用するパソコン | ダウンロード |
| --- | --- |
| Windows 10 / 11（64bit） | [DAMeter-win-x64.zip](https://github.com/atstti/DAMeter/releases/download/v0.1.6/DAMeter-win-x64.zip) |
| Mac・Apple Silicon（M1以降、macOS 15以降） | [DAMeter-osx-arm64.dmg](https://github.com/atstti/DAMeter/releases/download/v0.1.6/DAMeter-osx-arm64.dmg) |
| Mac・Intel（macOS 15以降） | [DAMeter-osx-x64.dmg](https://github.com/atstti/DAMeter/releases/download/v0.1.6/DAMeter-osx-x64.dmg) |

更新前に旧版を完全終了してください。WindowsはZIPを展開して `DAMeter.exe` を起動します。MacはDMGを開き、`DAMeter.app` を「アプリケーション」へ移動して起動します。.NETの別途インストールは不要です。Mac用のZIPと、各CPU向けの `SHA256SUMS-*.txt` もAssetsにあります。

## Mac版の変更

- フローティング中は盤面の縦横比を保って拡大縮小します。透明な上余白を取り除き、デスクトップ上端（メニューバーの下）まで盤面を寄せられる構成に変更しました。
- 画面上のマウス位置を基準にサイズを計算し、ドラッグ中のウィンドウ位置変更による座標のずれを避けます。ボタンを離した瞬間のサイズ再計算も廃止しました。
- 拡大は画面の作業領域内に制限します。旧版の保存設定は、見えていた盤面の位置と大きさを基準に変換します。

メーター本体の右下の角をドラッグしてください。3表示の切り替え、通常表示との往復、クリック透過からの復帰を維持しています。VUの説明文、Windows版の操作、音声取得処理は変更していません。

## Macの起動・収録許可

Mac版はad-hoc署名で、Developer ID署名・Apple公証はありません。初回起動がブロックされた場合は、配布元を確認し「システム設定 → プライバシーとセキュリティ」の「このまま開く」を使用してください。

許可済みでも収録許可の案内が繰り返し出る場合は、DAMeterを完全終了し、「画面収録とシステムオーディオ録音」の一覧からDAMeterを「−」で削除します。その後「＋」で `/Applications/DAMeter.app` を追加し、許可をオンにして起動してください。
