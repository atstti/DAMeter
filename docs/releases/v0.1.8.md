DAMeter 0.1.8の試用版です。Mac版のサイズ変更場所を分かりやすくしました。

## ダウンロード

| 使用するパソコン | ダウンロード |
| --- | --- |
| Mac・Apple Silicon（M1以降、macOS 15以降） | [DAMeter-osx-arm64.dmg](https://github.com/atstti/codex/releases/download/v0.1.8/DAMeter-osx-arm64.dmg) |
| Mac・Intel（macOS 15以降） | [DAMeter-osx-x64.dmg](https://github.com/atstti/codex/releases/download/v0.1.8/DAMeter-osx-x64.dmg) |
| Windows 10 / 11（64bit） | [DAMeter-win-x64.zip](https://github.com/atstti/codex/releases/download/v0.1.8/DAMeter-win-x64.zip) |

旧版を⌘Qで終了してから更新してください。MacはDMG内の `DAMeter.app` を「アプリケーション」に移して起動します。設定画面で0.1.8と表示されることを確認できます。

## Mac版の変更

- フローティング中も、右下に斜め両矢印のマークを常時表示します。
- マウスを重ねるとマークの色が変わり、サイズ変更できる場所を確認できます。
- 十字になっていたMacのカーソルを、専用の斜め両矢印へ変更しました。
- マークをドラッグして拡大・縮小できます。横型・縦型ピーク、アナログVUの3種類に対応します。

以前報告された突然大きくなる症状は引き続き調査中です。再発時は「設定 → 操作ログの場所を開く」から `interactions.jsonl` を取得できます。

## 検証と導入

既存の画面・入力・音声ライフサイクルの回帰テストと、Macの実ホバーイベント後のネイティブカーソル確認、拡縮・移動の反復検証を実施します。結果は [テスト結果](https://github.com/atstti/codex/blob/main/docs/TESTING.md) を参照してください。

詳しい導入・収録許可の手順は [Mac版の説明](https://github.com/atstti/codex/blob/v0.1.8/docs/MACOS.md) にあります。Mac版はad-hoc署名で、Developer ID署名・Apple公証はありません。各配布ファイルのSHA-256はAssetsの `SHA256SUMS-*.txt` にあります。
