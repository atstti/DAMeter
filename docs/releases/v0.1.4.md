Windows / Macで再生中のシステム音声を、横型ピーク・縦型ピーク・アナログVUで表示するDAMeter 0.1.4の試用版（Pre-release）です。

## ダウンロード

下の **Assets** または次のリンクから、自分のパソコンに合うファイルを選んでください。

| 使用するパソコン | ダウンロード |
| --- | --- |
| Windows 10 / 11（64bit） | [DAMeter-win-x64.zip](https://github.com/atstti/DAMeter/releases/download/v0.1.4/DAMeter-win-x64.zip) |
| Mac・Apple Silicon（M1以降、macOS 15以降） | [DAMeter-osx-arm64.dmg](https://github.com/atstti/DAMeter/releases/download/v0.1.4/DAMeter-osx-arm64.dmg) |
| Mac・Intel（macOS 15以降） | [DAMeter-osx-x64.dmg](https://github.com/atstti/DAMeter/releases/download/v0.1.4/DAMeter-osx-x64.dmg) |

WindowsはZIPを展開し、`DAMeter.exe` を起動します。MacはDMGを開き、`DAMeter.app` を「アプリケーション」へ移動して起動します。更新前に旧版を完全終了してください。.NETの別途インストールは不要です。

Mac用のアプリ入りZIPと、各CPU向けの `SHA256SUMS-*.txt` もAssetsにあります。`Source code` は開発用です。アプリを使う場合は上のZIPまたはDMGを選びます。

## 0.1.4の変更

- Mac版のフローティング表示で、メーター周囲の大きな半透明背景と右下のサイズ変更マークを初期状態から非表示にしました。移動、透明な右下隅でのサイズ変更、右クリックメニューは残しています。
- 設定の「フローティングの周囲の背景を表示」で背景を戻せます。表示設定と不透明度を保存します。
- Windows版とMac版を、このReleasesページから直接ダウンロードできるようにしました。

Windows版のフローティング表示は従来どおりです。今回の枠を隠す変更はMac版が対象で、音声取得コードは変更していません。WindowsはWPF / NAudio WASAPI Loopback、MacはAvalonia / ScreenCaptureKitを使用します。音声の録音・ファイル保存・外部送信は行いません。

## Macの起動・収録許可

このMac版はad-hoc署名で、Developer ID署名・Apple公証はありません。初回起動がブロックされた場合は、配布元を確認し「システム設定 → プライバシーとセキュリティ」の「このまま開く」を使用してください。

許可がオンでも収録許可のダイアログが繰り返し出る場合は、DAMeterを完全終了し、「画面収録とシステムオーディオ録音」の一覧からDAMeterを「−」で削除します。その後「＋」で `/Applications/DAMeter.app` を追加し、許可をオンにして起動してください。0.1.3では、この再登録によりApple Silicon Macで実音声に反応したとのユーザー確認がありました。

## 検証

Core 46件・Mac UI／音声連携46件、計92件の自動テストと、Windows／Apple Silicon／Intel向けのビルド・配布物生成を確認しています。Macの署名、音声ライブラリの読み込み、権限不要のPCM変換、起動・終了もCIで検証しています。0.1.4のフローティング操作とWindowsの実音声取得を含む実機確認は未完了です。
