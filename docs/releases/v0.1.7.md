DAMeter 0.1.7の試用版です。Mac版のフローティング移動を改善し、サイズ変更の問題を調べるための記録を追加しました。

**サイズ変更中に突然大きくなる症状は、原因と解消をまだ確認できていません。** この版で修正済みとは断定していません。

## ダウンロード

| 使用するパソコン | ダウンロード |
| --- | --- |
| Mac・Apple Silicon（M1以降、macOS 15以降） | [DAMeter-osx-arm64.dmg](https://github.com/atstti/codex/releases/download/v0.1.7/DAMeter-osx-arm64.dmg) |
| Mac・Intel（macOS 15以降） | [DAMeter-osx-x64.dmg](https://github.com/atstti/codex/releases/download/v0.1.7/DAMeter-osx-x64.dmg) |
| Windows 10 / 11（64bit） | [DAMeter-win-x64.zip](https://github.com/atstti/codex/releases/download/v0.1.7/DAMeter-win-x64.zip) |

旧版を⌘Qで終了してから更新してください。MacはDMG内の `DAMeter.app` を「アプリケーション」に移して起動します。設定画面に表示される版が0.1.7であることを確認できます。.NETの追加インストールは不要です。

## Mac版の変更

- フローティングの移動をアプリ側で制御し、移動中はサイズを変更せず、メニューバー下の作業領域の上端まで配置します。
- アナログVUの左右の盤面の間にある透明な部分からもドラッグできるようにしました。
- 表示切り替え直後の位置補正で、更新前後の異なる寸法を混ぜないようにしました。
- 設定画面にバージョンと「操作ログの場所を開く」を追加しました。再現したらマウスを離して、Finderで開いたフォルダーの `interactions.jsonl` を取得できます。記録はこのMac内だけに保存し、音声や他のアプリの内容は含めません。

Windows版と音声取得処理は変更していません。Macの収録許可が更新後に必要な場合の再登録手順は [Mac版の説明](https://github.com/atstti/codex/blob/v0.1.7/docs/MACOS.md) を参照してください。

## 検証範囲

Macの画面・入力・音声ライフサイクルなどの回帰テストに加え、AppKitのマウスイベントと実際のQuartz座標によるネイティブの拡縮・上端移動テストをCIへ追加しました。物理マウスボタン状態はテスト用に置き換えるため、ユーザーのMacでの症状の解消は別途確認が必要です。詳しい結果は [テスト結果](https://github.com/atstti/codex/blob/v0.1.7/docs/TESTING.md) を参照してください。

Mac版はad-hoc署名で、Developer ID署名・Apple公証はありません。配布ファイルのSHA-256はAssetsの `SHA256SUMS-*.txt` にあります。
