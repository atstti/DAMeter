# DAMeter Mac版

## 0.1.6：サイズの跳ねと上端の透明な余白を修正

フローティング表示は盤面に合わせた縦横比を保って拡大縮小します。周囲の透明な余白を取り除き、デスクトップ作業領域の上端（メニューバーの下）に盤面を寄せられる構成へ変更しました。VUの説明文は残しています。

右下の角をドラッグすると、横方向・縦方向の動きの両方から拡大縮小量を計算します。Macでは画面上のマウス位置を直接読み、ウィンドウ移動や描画更新で座標が変わってもサイズ計算へ混入させません。ボタンを離すと最後に表示したサイズで操作を終了します。画面の作業領域を超える拡大は制限します。

旧版の設定は、見えていた盤面の位置と大きさを基準に一度だけ変換します。通常表示の位置とサイズは維持します。0.1.6のフローティング最小寸法は縦横比に応じて決まり、0.1.5までの120×120固定とは異なります。音声取得は変更していません。

## 0.1.5：フローティング中のサイズ変更を見直し

フローティング中は、見えているメーター本体の右下隅へカーソルを合わせてドラッグします。操作領域は、透明な余白を含むウィンドウの隅ではなく、メーターの盤面の隅に配置します。横型ピーク・縦型ピーク・アナログVUの3表示に対応し、表示形式やサイズが変わっても盤面の位置に追従します。

ドラッグ開始時にポインターを捕捉し、ウィンドウ内の座標を基準に幅・高さを計算する処理へ変更しました。ボタンを離した場合や捕捉が解除された場合は、サイズ変更中の状態を解放します。フローティング表示の最小サイズは120×120で、そこまで縮めた後も再び拡大できる構成です。

メーター本体のドラッグによる移動、右クリックメニュー、周囲の背景を初期状態で隠す設定は維持しています。クリック透過中はメニューバーからウィンドウを表示すると透過を解除できます。音声取得コードは変更していません。今回の繰り返しサイズ変更はMac実機で未確認です。自動テスト・CIで確認した範囲は [TESTING.md](TESTING.md) に記録します。

## 0.1.4：フローティングの周囲の枠を非表示

フローティング表示では、メーターを囲む大きな半透明の背景と右下のサイズ変更マークを初期状態で表示しません。メーター本体の盤面・バー・文字の視認性は維持します。

周囲の背景を戻す場合は、設定の「フローティングの周囲の背景を表示」をオンにしてください。背景を表示している間は、不透明度を0～100%で調整できます。背景の表示設定は保存され、再起動後も復元されます。

メーターの右クリックメニューから表示形式の変更や通常表示への復帰もできます。0.1.5でも周囲の枠は表示せず、サイズ変更の操作領域をメーター本体の右下隅へ追従させます。

## 0.1.3：DAMeter本体での音声取得

DAMeter本体の中でシステム音声を取得する構成に変更しました。macOSで許可したDAMeter自身がScreenCaptureKitを呼び出すため、音声取得用の別アプリへの許可は不要です。設定で確認する項目は「DAMeter」です。

更新前に旧版を⌘Qまたは「終了」ボタンで終了し、新しいDMGの `DAMeter.app` で「アプリケーション」内の旧版を置き換えてください。操作できない場合は⌘＋⌥＋Escで旧版を強制終了します。

通常画面または設定画面の「権限設定」からmacOSの設定を開けます。許可がオンでも取得できない場合は、下記の「許可済みでも毎回アクセス許可を求められる場合」の手順で、現在のアプリを登録し直してください。

macOS のシステム音声を表示する Avalonia / .NET 10 アプリです。Windows版の WPF / WASAPI 実装を維持し、音声解析、ピーク・RMS計算、表示応答、JSON設定を共有しています。

## 動作対象

- macOS 15 以降の、使用する .NET 10 ランタイムがサポートするバージョン
- Apple Silicon: `osx-arm64`（M1 / M2 / M3 / M4 など）
- Intel Mac: `osx-x64`

音声取得には macOS 標準の ScreenCaptureKit を使用します。ScreenCaptureKit の音声APIは macOS 13 以降で利用できますが、本アプリの対応OSは .NET 10 のサポート範囲に合わせています。自己完結型なので、配布アプリの実行時に .NET SDK を別途インストールする必要はありません。

## ダウンロードと起動

**[0.1.6試用版のダウンロードページ](https://github.com/atstti/codex/releases/tag/v0.1.6)** のAssetsから、使用するMacに合ったDMGを選びます。試用版を含む配布一覧は [Releases](https://github.com/atstti/codex/releases) にあります。

| 使用するMac | 0.1.6のダウンロード |
| --- | --- |
| Apple Silicon（M1以降） | [DAMeter-osx-arm64.dmg](https://github.com/atstti/codex/releases/download/v0.1.6/DAMeter-osx-arm64.dmg) |
| Intel | [DAMeter-osx-x64.dmg](https://github.com/atstti/codex/releases/download/v0.1.6/DAMeter-osx-x64.dmg) |

1. 使用中のDAMeterを⌘Qまたは「終了」で完全終了します。
2. ダウンロードしたDMGを開き、`DAMeter.app` を「アプリケーション」へドラッグします。旧版がある場合は置き換えます。
3. 「アプリケーション」内の `DAMeter.app` を起動します。

DMGの代わりに、同じCPU向けの `DAMeter-osx-arm64.zip` または `DAMeter-osx-x64.zip` を展開してアプリを移動する方法も使えます。ReleasesのファイルはActionsのArtifactsを展開し直す必要がなく、直接ダウンロードできます。`Source code` は開発用ソース一式です。実音声の取得と許可ダイアログの確認は、インストール後のMacで行ってください。

「このMacについて」で「チップ: Apple M…」と表示される場合は Apple Silicon、「プロセッサ: Intel…」と表示される場合は Intel です。

この開発ビルドは **ad-hoc署名で、Developer ID署名・Apple公証はありません**。初回起動がmacOSにブロックされた場合は、内容と配布元を確認したうえで「システム設定 → プライバシーとセキュリティ」の「このまま開く」を使用してください。Gatekeeper全体を無効化する必要はありません。

## システム音声へのアクセス許可

ScreenCaptureKit では、システム音声の取得に「画面収録」または「画面とシステムオーディオの収録」に関する許可が必要です。表示名はmacOSのバージョンによって異なります。初回起動時のダイアログでDAMeterを許可し、必要に応じてアプリを終了して再起動してください。「システム設定 → プライバシーとセキュリティ」で「DAMeter」へのアクセスを確認できます。

アプリは画面フレームの受信先を登録せず、音声のみを処理します。マイクは取得しません。音声バッファはDAMeter本体のメモリ内で解析され、処理後に破棄されます。音声・画面のファイル保存、録画、外部送信は行いません。権限を拒否した場合は状態表示を確認し、システム設定で許可を変更してから再試行してください。

### 許可済みでも毎回アクセス許可を求められる場合

アプリの更新後などに、設定の許可がオンでも「DAMeterの許可を確認してください」と表示されたり、起動のたびに収録許可のダイアログが出たりする場合があります。0.1.3では、次の再登録で実際に音声メーターが動くことをユーザーのMacで確認しました。

1. DAMeterを⌘Qまたは「終了」ボタンで完全に終了します。
2. 新しい `DAMeter.app` を「アプリケーション」へ入れ、その場所から起動するようにします。
3. システム設定 → プライバシーとセキュリティ →「画面収録とシステムオーディオ録音」を開きます。項目名はmacOSのバージョンによって異なります。
4. 一覧の `DAMeter.app` を選び、「−」で削除します。
5. 「＋」から「アプリケーション」内の `/Applications/DAMeter.app` を追加し、許可をオンにします。
6. DAMeterを起動し、音声を再生してください。macOSからアプリの再起動を求められた場合は、その案内に従います。

この再登録で解消したケースでは、Mac全体の再起動は不要でした。

## 表示とWindows版との差分

- 横型ピーク、縦型ピーク、アナログVUの3種類を切り替えられます。
- ピーク・RMS・dBFS、ホールド、減衰、クリップ判定はWindows版と同じ共通処理を使用します。
- VUは約300msのRMSエネルギー応答による近似表示であり、厳密な規格準拠ではありません。
- フローティング表示、周囲の背景の表示切替・不透明度、最前面、クリック透過、メニューバーからの復帰をMac向けに実装しています。
- ScreenCaptureKitでシステム音声を取得する方式のため、Windows版のWASAPI出力エンドポイント選択はありません。Macのシステムサウンド設定で出力先を選びます。
- DRMなどで保護されたコンテンツ、ヘッドレス環境、アプリやOS側の取得制限によって、音声を取得できない場合があります。

クリック透過で操作できなくなった場合は、メニューバーのDAMeterアイコンから表示・通常表示への復帰を選びます。音声の反応がない場合は、権限、システム音声の再生、状態表示を確認してください。

## Macでの開発と配布ビルド

前提は `global.json` に指定した .NET 10 SDK と、Xcodeコマンドラインツールです。リポジトリのルートで実行します。

```bash
# C#の復元・ビルド・共通テスト
dotnet restore src/DAMeter.Mac/DAMeter.Mac.csproj --locked-mode
dotnet build src/DAMeter.Mac/DAMeter.Mac.csproj --configuration Release --no-restore --warnaserror
dotnet restore tests/DAMeter.Core.Tests/DAMeter.Core.Tests.csproj --locked-mode
dotnet test tests/DAMeter.Core.Tests/DAMeter.Core.Tests.csproj --configuration Release --no-restore

# Apple Silicon向けの自己完結アプリ・ZIP・DMG
bash scripts/publish-macos.sh osx-arm64

# Intel向け
bash scripts/publish-macos.sh osx-x64
```

生成先はそれぞれ `artifacts/macos-osx-arm64/`、`artifacts/macos-osx-x64/` です。自己完結型の単一 .NET 実行ファイルを `DAMeter.app/Contents/MacOS/DAMeter.Mac`、Swift音声ライブラリを `DAMeter.app/Contents/Frameworks/libDAMeterAudio.dylib` に配置します。ライブラリはDAMeter本体へ読み込まれ、同じプロセス内でScreenCaptureKitを呼び出します。開発中も配布スクリプトで組み立てた `.app` を起動してください。

macOSの署名規則に合わせてマネージDLLをコード用ディレクトリへ直接配置せず、.NETの単一ファイル機能で組み込みます。.NETに同梱するネイティブランタイムは実行時にユーザーの一時領域へ展開されます。Swift音声ライブラリを先にad-hoc署名し、JIT用entitlementを付けたアプリ全体の署名と整合性を検証します。

スクリプトは Swift のコンパイル、署名検証、Avaloniaの実ウィンドウで3表示を描画して閉じる `--smoke-test`、ZIP・DMG・SHA-256生成を行います。スモークテストでは音声取得・設定保存を開始せず、通常起動と同じライブラリの読み込み、メインアプリの識別子 `org.atstti.DAMeter`、PCM変換を確認します。メニューバーを用意した状態でmacOSの通常の終了操作も確認します。異なるCPU向けへのクロス発行時は実行確認を省略します。GitHub Actions はCPUに一致するmacOSランナーでそれぞれビルドします。

通常のC#ビルドと、CPUごとの自己完結発行は異なるNuGetロックファイルを使います。依存関係変更時は対応するロックファイルも更新してください。

## 検証範囲

Linuxで検証できるのは、C#のビルド、共通数値処理、設定保存、ネイティブ連携の状態管理などです。Swift / macOSフレームワークのコンパイルと署名・パッケージ作成はmacOSで行います。

CIのビルドや権限不要チェックに成功しても、ユーザーのMacでの実音声、権限ダイアログ、メーター描画、透過からの復帰が確認されたことにはなりません。以下は実機での確認が必要です。

- 初回アクセス許可、拒否した状態、許可変更後の再試行
- ブラウザ・音楽プレーヤーなどの実音声、無音、L/R独立信号
- 3表示、VU基準レベル、ホールド、減衰、クリップ
- フローティングの移動・メーター本体の右下隅での繰り返し拡大縮小と最小サイズからの復帰、周囲の背景の表示切替・不透明度0/50/100%、最前面
- クリック透過中のメニューバーからの復帰、終了時の音声取得停止
- 再起動時の設定復元、複数モニター、Retina、高DPI、モニター切断
- 長時間動作時のCPU・メモリ・ハンドル数
